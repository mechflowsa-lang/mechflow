DIVISION 02 — FLUID & GAS SEALING TECHNOLOGIES

API 682 & API 692 Sealing Systems

State-of-the-art cleanroom assembly, 150-bar dynamic Nitrogen compressor dry gas seal test rig, optical monochromatic flat helium lapping, and Root Cause Failure Analysis (RCFA).

High-Tech Sealing Infrastructure

Cleanroom Testing & Sub-Micron Precision

MechFlow operates specialized positive-pressure ISO Class 7 cleanrooms and dynamic test stands capable of verifying mechanical seals and dry gas seal cartridges under extreme operating pressures and temperatures.

• Dry Gas Seals (DGS) for Gas Compressors (API 692)

Single, tandem, and tandem with intermediate labyrinth configurations tested with inert Nitrogen up to 150 bar dynamic pressure and recorded lift-off speeds.

• Optical Monochromatic Helium Light Band Lapping

Silicon Carbide (SiC), Tungsten Carbide (TC), and Carbon face lapping achieving absolute flatness within 1-2 helium light bands (0.3 - 0.6 microns).

• API 682 Dynamic Seal Test Rig (120 Bar / 85°C)

Full operational testing under simulated process temperatures and pressures with automated telemetry logging of barrier fluid pressure, flow, and face temperature.

• Root Cause Failure Analysis (RCFA)

Microscopic examination of blistered, eroded, or thermally cracked seal faces to redesign piping plans and extend MTBF by 300%+.

Sealing Specifications

  • DGS Dynamic Test Pressure: Up to 150 Bar (N₂)
  • Surface Flatness: < 0.6 µm (2 Helium Bands)
  • Cleanroom Standard: ISO 14644 Class 7
  • Compliance: API 682 & API 692
