النفط والغاز والتكرير

حلول الآلات الدوارة عالية الضغط والمصممة لمقاومة غاز كبريتيد الهيدروجين الحامضي H2S، والضغوط الفائقة، والظروف المناخية القاسية للخليج.

مضخات تصدير الزيت وتغذية المعالجة API 610 (BB2 / BB3 / BB5)
ضواغط الغاز الطاردة المركزية API 617 والتوربينات البخارية API 612
الأختام الغازية الترادفية (API 692) وخراطيش Plan 53B المعتمدة
المعايير المعتمدة: API 610 / 682 / 692

البتروكيماويات والصناعات الكيميائية

خدمات الإحكام الميكانيكي والتشغيل الدقيق لخطوط السوائل الكيميائية المسببة للتآكل، مفاعلات البلمرة، ووحدات تكسير الإيثيلين.

أختام خلاطات ومفاعلات البلمرة العلوية (API 682 Plan 54)
تنعيم أسطح الأختام بالهيليوم (2 Light Bands) بالغرف النظيفة
إدارة وشد وصلات الفلانجات ASME PCC-1 أثناء عمرات الإيقاف
المعايير المعتمدة: ASME PCC-1 / API 682

تحلية المياه والمرافق (SWCC)

صيانة شاملة لمضخات التناضح العكسي عالي الضغط (SWRO)، مضخات سحب مياه البحر الرأسية، وأجهزة استرداد الطاقة (ERD).

تصنيع دواسر السوبر دوبلكس والموازنة الديناميكية الدقيقة
طلاءات HVAF تنجستن كاربيد المقاومة للتكهف والتآكل البحري
تأهيل المضخات الغاطسة واختبارات العزل الكهربائي
المعايير المعتمدة: ISO 10816-7 / ISO G1.0

توليد الكهرباء والمحطات (SEC / IPPs)

دعم محطات التوليد الحرارية والدورة المركبة بعمرات مضخات تغذية المراجل البخارية، فحص روتورات التوربينات، وصيانة المولدات.

إعادة هندسة مضخات تغذية المراجل متعددة المراحل (+350% MTBF)
مسح حجاب التوربينات البخارية وصب محامل البابت وتنعيمها
لف ملفات المولدات فئة Class H والتشريب VPI حتى 13.8kV
المعايير المعتمدة: API 612 / IEEE 522

التعدين والمعادن (معادن)

صيانة المعدات الثقيلة المقاومة للتآكل الاحتكاكي الشديد في مصانع الفوسفات والبوكسيت واستخلاص الذهب والمعادن.

تأهيل أجزاء مضخات الملاط الكاشط (Slurry) وتلبيس الأعمدة
إعادة لف محركات طواحين الخام SAG Mill حتى 3,500kW خلال 9 أيام
موازنة ديناميكية حتى 10 طن لمراوح وسواحب الأفران الثقيلة
المعايير المعتمدة: ASTM G65 / ISO G2.5

الموانئ والمنشآت البحرية

صيانة خطوط الدفع البحري، حزم أنابيب التبريد بمياه البحر، ومضخات مناولة السوائل في ميناء الملك فهد وميناء الملك عبدالعزيز.

محاذاة ليزرية لاسلكية لخطوط الدفع البحرية حتى إزاحة 50 متراً
تشغيل وتنعيم الفلانجات موقعياً والقطع البارد من 2 إلى 120 بوصة
صيانة وتتييب المبادلات الصفائحية وتجديد الجوانات المقاومة للملوحة
المعايير المعتمدة: IACS Marine / ASME VIII
