النفط والغاز والتكرير

حلول الآلات الدوارة لبيئات غاز H2S الحامضي، والضغوط العالية والحرارة الشديدة.

مضخات تصدير الزيت وتغذية المعالجة API 610 (BB2 / BB3 / BB5)
ضواغط الغاز الطاردة API 617 والتوربينات البخارية API 612
الأختام الغازية الترادفية (API 692) وخراطيش Plan 53B المعتمدة
المعايير المعتمدة: API 610 / 682 / 692

البتروكيماويات والصناعات الكيميائية

خدمات الإحكام الميكانيكي لخطوط السوائل الكيميائية الكاشطة ومفاعلات البلمرة.

أختام خلاطات ومفاعلات البلمرة العلوية (API 682 Plan 54)
تنعيم أسطح الأختام بالهيليوم (2 Light Bands) بالغرفة النظيفة
إدارة وشد وصلات الفلانجات ASME PCC-1 أثناء العمرات
المعايير المعتمدة: ASME PCC-1 / API 682

تحلية المياه والمرافق (SWCC)

صيانة مضخات التناضح العكسي (SWRO)، مضخات السحب الرأسية، وأجهزة استرداد الطاقة.

تصنيع دواسر السوبر دوبلكس والموازنة الديناميكية الدقيقة
طلاءات HVAF تنجستن كاربيد المقاومة للتكهف والتآكل
تأهيل المضخات الغاطسة واختبارات العزل الكهربائي
المعايير المعتمدة: ISO 10816-7 / ISO G1.0

توليد الكهرباء والمحطات (SEC)

دعم محطات التوليد: عمرات مضخات المراجل، فحص روتورات التوربينات، وصيانة المولدات.

إعادة هندسة مضخات تغذية المراجل متعددة المراحل (+350% MTBF)
مسح حجاب التوربينات البخارية وصب وتنعيم محامل البابت
لف ملفات المولدات فئة Class H والتشريب VPI حتى 13.8kV
المعايير المعتمدة: API 612 / IEEE 522

التعدين والمعادن (معادن)

صيانة المعدات الثقيلة المقاومة للتآكل في مصانع الفوسفات، البوكسيت، والذهب.

تأهيل أجزاء مضخات الملاط الكاشط (Slurry) وتلبيس الأعمدة
إعادة لف محركات طواحين SAG Mill حتى 3,500kW في 9 أيام
موازنة ديناميكية حتى 10 طن لمراوح وسواحب الأفران
المعايير المعتمدة: ASTM G65 / ISO G2.5

الموانئ والمنشآت البحرية

صيانة خطوط الدفع البحري، مبادلات التبريد بمياه البحر، ومضخات مناولة السوائل.

المعايير المعتمدة: IACS Marine / ASME VIII
